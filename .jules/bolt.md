## 2024-05-22 - React Router searchParams.getAll() Memoization Trap
**Learning:** In React Router, `useSearchParams()[0].getAll()` returns a *new array reference* on every single render. If this array is used directly in a dependency array for a memoized hook (like `useMemo` or `useCallback`), it breaks memoization entirely, causing the hook to re-run on every render and defeating the purpose of the optimization. This is a subtle and codebase-specific performance trap when handling complex URL-based state like multiple filter arrays.
**Action:** When extracting arrays from `searchParams.getAll()` for use in memoized derivations, explicitly stringify the arrays into separate variables (e.g., `const vibeFilterStr = JSON.stringify(vibeFilter)`) and use the stringified variable in the dependency array. Bypass ESLint's `react-hooks/exhaustive-deps` warning for the missing raw array using an inline comment. This preserves referential equality of the dependencies and ensures `useMemo` properly caches the derived state.
