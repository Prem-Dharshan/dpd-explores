## 2024-10-27 - React Router useSearchParams().getAll() memoization trap
**Learning:** `useSearchParams()[0].getAll("key")` returns a new array reference on every render. If used in dependencies for `useCallback` or `useMemo`, it breaks memoization and causes those hooks to run continuously on every render, which can lead to severe performance bottlenecks for computationally expensive filtering/sorting operations.
**Action:** When deriving synchronous state using array parameters from React Router, use `useMemo` (rather than `useCallback`) directly. To preserve memoization without triggering ESLint's exhaustive-deps warning for complex arrays, stringify the raw array into a separate variable (`const stringified = JSON.stringify(rawArray)`), and use the stringified variable as the dependency in a `useMemo` that returns the raw array. Prefix with `// eslint-disable-next-line react-hooks/exhaustive-deps` to suppress the missing dependency error for the raw array.
