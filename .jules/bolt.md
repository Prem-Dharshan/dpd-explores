## 2024-05-14 - Replace useCallback with useMemo for synchronously derived state
**Learning:** Using `useCallback` for derived state that is immediately invoked during render (`const displayedPlaces = filtered()`) negates any optimization and runs synchronously on every render. To properly memoize derived state filtering arrays based on URL search parameters (like in React Router), `useMemo` must be used. Also, since `searchParams.getAll()` returns a new array reference on every render, it shouldn't be passed directly in the dependency array; stringifying the array and passing the stringified result alongside `// eslint-disable-next-line react-hooks/exhaustive-deps` prevents unnecessary recalculations.
**Action:** When deriving state synchronously based on external query parameters, default to `useMemo` over `useCallback`, and handle new array references from hooks like `useSearchParams()` by assigning stringified values to separate variables for the dependency array to properly take advantage of React's memoization.
