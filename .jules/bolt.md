## 2024-10-13 - Dashboard Rendering Performance Optimization
**Learning:** React Router's `useSearchParams()[0].getAll()` returns a new array reference on every single render. Using it directly in a dependency array causes the memoization hook to invalidate on every render. Furthermore, using `useCallback` to define an expensive function and immediately calling it inside the render cycle (e.g. `const displayedPlaces = filtered()`) defeats the entire purpose of memoization, resulting in O(N) filtering running synchronously on every render and blocking the main thread.
**Action:** Use `useMemo` instead of synchronously invoking `useCallback`. To memoize arrays correctly that lose reference between renders like those from `getAll()`, serialize them first (e.g., `const stringifiedArray = JSON.stringify(rawArray)`), pass the serialized string to the dependency array, and use `// eslint-disable-next-line react-hooks/exhaustive-deps` to prevent exhaustive-deps warnings for missing raw arrays.
