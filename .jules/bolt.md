## 2024-06-25 - [React Router useSearchParams memoization break]
**Learning:** `useSearchParams()[0].getAll()` returns a new array reference on every single render in React Router. This breaks memoization dependencies (like `useMemo` and `useCallback`) that rely on those arrays, causing expensive filtering or sorting operations to run redundantly on unrelated state changes.
**Action:** When extracting arrays via `searchParams.getAll()`, manually memoize the array. To satisfy the ESLint `exhaustive-deps` rule while avoiding stringifying directly inside the array (which violates the "simple expression" rule), stringify the raw array to a separate variable (`const strArr = JSON.stringify(rawArr)`), use the raw array in a `useMemo` that depends on `strArr`, and use `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the warning.
