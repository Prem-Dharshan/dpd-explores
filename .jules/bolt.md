## 2025-01-29 - Memoize synchronously derived state to avoid unnecessary renders
**Learning:** `useSearchParams()[0].getAll()` returns a new array reference on every single render. When passed as a dependency or used within a component render without memoization (like invoking a `useCallback` on every render), it can trigger redundant processing and potentially re-renders. We should use `useMemo` for synchronously derived state instead of `useCallback`.
**Action:** When working with arrays from `searchParams.getAll()`, explicitly stringify the array output (e.g. `JSON.stringify(arr)`) to capture the values, pass the stringified variable to the `useMemo` dependency array, and use `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the missing raw array warning. This ensures memoization behaves correctly for stable arrays.
