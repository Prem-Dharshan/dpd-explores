## 2025-05-19 - UseMemo Instead of UseCallback for Derived State SearchParams Filtering
**Learning:** In React Router, `useSearchParams()[0].getAll()` returns a new array reference on every render, which will break any memoization (or `useCallback`) if the raw arrays are passed directly into the dependency list. Combining synchronous state derivation with `useCallback` plus an immediate function invocation is an anti-pattern that leads to unnecessary computations on every single render (because the function is recreated on every render and re-executed).
**Action:** Use `useMemo` for synchronously derived state instead of `useCallback()()`. Always stringify arrays derived from `searchParams.getAll()` (e.g., `JSON.stringify(rawArray)`) and pass the stringified variable into the dependency list, combined with `// eslint-disable-next-line react-hooks/exhaustive-deps` above the closing dependency array bracket to satisfy ESLint while avoiding the raw array warning.
