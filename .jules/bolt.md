## 2024-05-24 - [Avoid breaking memoization with searchParams.getAll]
**Learning:** `useSearchParams()[0].getAll()` returns a new array reference on every render. Passing it as a dependency in a `useCallback` or `useMemo` will break memoization because the array reference changes every render. Using such dependencies inside a `useCallback` that computes synchronously derived state essentially causes the app to re-evaluate state on every single render.
**Action:** When `getAll()` result is required in the dependency array, stringify the list to a string variable (e.g. `const listStr = JSON.stringify(list)`) and provide `listStr` in the dependency array to preserve memoization and avoid unnecessary execution. Use `// eslint-disable-next-line react-hooks/exhaustive-deps` to satisfy ESLint warnings. Additionally, use `useMemo` for derived state rather than relying on an executed `useCallback`.
