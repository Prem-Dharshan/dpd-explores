## 2024-08-12 - [Optimizing React Router searchParams.getAll() filtering]
**Learning:** Using `useSearchParams()[0].getAll()` returns a new array reference on every render, which completely breaks array dependency memoization (e.g., `useCallback` or `useMemo` dependencies). Additionally, invoking `useCallback()` strictly for synchronously deriving state to immediately consume it is an anti-pattern.
**Action:** When filtering with arrays derived from `searchParams.getAll()`, serialize them explicitly into strings (e.g., `JSON.stringify()`) to a separate variable, inject the stringified version into the dependencies of a `useMemo` hook, and use an eslint disable block for the exhaustive-deps warning to preserve true memoization. Additionally, map lists of items into components wrapped with `React.memo` to skip unneeded re-renders during interactions that only impact parent state (like text input updates).
