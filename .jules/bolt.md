## 2024-11-03 - Prevent re-renders by switching to useMemo for derived state
**Learning:** In React Router, `useSearchParams()[0].getAll()` returns a new array reference on every render, which can cause infinite re-renders or break memoization if used directly in a dependency array. Additionally, using an immediately invoked `useCallback` (e.g. `const displayedPlaces = filtered()`) completely defeats memoization and causes a full array scan, filter, and sort on every render cycle.
**Action:** Extract the stringified value into a variable first (e.g., `const arrStr = JSON.stringify(rawArray)`) and use `useMemo(() => JSON.parse(arrStr), [arrStr])` before passing it to dependency arrays. For synchronously derived state like filtering/sorting lists, strictly use `useMemo` instead of defining a `useCallback` and invoking it immediately on every render.
