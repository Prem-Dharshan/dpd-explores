## 2025-05-18 - React Router `useSearchParams` array reference breaking memoization
**Learning:** In this codebase, `searchParams.getAll()` (e.g. from React Router's `useSearchParams`) returns a new array reference on every render. If these arrays are used directly in the dependency array of `useMemo` or `useCallback` (e.g. for derived state or memoized filters), it completely breaks the memoization, causing those hooks to recalculate on every single render.
**Action:** When extracting arrays from `useSearchParams`, serialize them to strings (e.g. `JSON.stringify(rawArray)`) outside of the dependency array, and use the stringified variable in the dependency array. Add `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the ESLint warning for missing the raw array.
