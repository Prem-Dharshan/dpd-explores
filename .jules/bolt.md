## 2024-03-22 - Memoizing derived state from URLSearchParams
**Learning:** `searchParams.getAll()` returns a new array reference on every render, which breaks React's dependency arrays (e.g. triggering continuous renders or defeating `useMemo`). Additionally, for synchronously derived state, wrapping it in `useCallback` and invoking it immediately (`const displayedPlaces = filtered()`) defeats the purpose of caching, causing the function to run on every render anyway.
**Action:** When filtering data based on multiple search params returned as arrays, stringify them for the dependency array (e.g. `JSON.stringify(searchParams.getAll('vibe'))`) and ignore ESLint dependency warnings, and always use `useMemo` for derived state directly instead of `useCallback` that gets invoked synchronously.
