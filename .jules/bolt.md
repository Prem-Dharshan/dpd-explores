## 2025-01-20 - Memoization Broken by React Router's URLSearchParams
**Learning:** React Router's `useSearchParams()[0].getAll('key')` returns a new array reference on every single render. Using it directly inside a dependency array for hooks like `useMemo` or `useCallback` will cause the hook to needlessly re-evaluate on every render, defeating the purpose of memoization and causing performance issues (especially for filtering/sorting operations).
**Action:** When using arrays returned by `searchParams.getAll()` as dependencies in hooks, serialize them outside the hook (e.g. `const arrayStr = JSON.stringify(array)`) and use the stringified variable in the dependency array. You'll need to use `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the linter warning about the missing raw array, but this is necessary for correctness and performance.
