## 2024-05-18 - [Memoization Anti-patterns in React Router Filter Logic]
**Learning:** React Router's `useSearchParams()[0].getAll()` returns a new array reference on every render. Passing this directly to a dependency array of `useCallback` or `useMemo` will break memoization. Furthermore, defining a filtering function with `useCallback` and immediately invoking it inside the render cycle synchronously (e.g. `const displayed = filtered()`) evaluates the O(N) filtering logic on every render, completely defeating the purpose of the hook since it only memoizes the *function definition*, not the *function execution*.
**Action:** Use `useMemo` for derived states like list filtering instead of `useCallback` immediately invoked. Assign stringified representations of search param arrays (`JSON.stringify(rawArray)`) to intermediate variables, pass those variables into the dependency array, and bypass ESLint's raw array dependency warnings to maintain stable references.
