## 2024-05-18 - useCallback for synchronously derived state anti-pattern
**Learning:** Returning a new array from `useCallback` on every render (e.g. `const displayedPlaces = filtered()`) defeats the purpose of React's memoization, as the function is still invoked continuously. Additionally, `useSearchParams()[0].getAll()` returns a new array reference on every render, which will break any memoization dependency arrays it is included in.
**Action:** Use `useMemo` directly for synchronously derived state instead of invoking a `useCallback` on every render. To memoize values derived from `searchParams.getAll()`, stringify the array output before passing it into the dependency array and use `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the missing raw array dependency warning.
