## 2024-08-04 - React Router useSearchParams breaks memoization with getAll()
**Learning:** `useSearchParams()[0].getAll()` returns a new array reference on every render, which breaks React's dependency array checks (like in `useMemo` or `useCallback`) causing continuous recalculations even when the query parameters haven't changed. Also, using `useCallback` for synchronously derived state is an anti-pattern as it requires invoking the callback on every render to get the value.
**Action:** Always memoize derived state directly using `useMemo` instead of wrapping a function in `useCallback`. When an array is retrieved via `getAll()` from URL search params, stringify it (`JSON.stringify(rawArray)`) to a separate variable outside the dependency list, and pass that variable to the dependency list with `// eslint-disable-next-line react-hooks/exhaustive-deps` to preserve referential equality without triggering lint errors.
