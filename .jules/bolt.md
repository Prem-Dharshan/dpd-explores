## 2025-02-12 - Synchronous Derived State Invocation in React
**Learning:** `useCallback` is frequently incorrectly used for derived state calculations that are then invoked synchronously during the render cycle (e.g., `const calc = useCallback(() => ..., [...]); const data = calc()`). This negates the memoization completely, as the expensive calculation is run on every render regardless of dependency changes. Furthermore, URL parameter collections like `useSearchParams()[0].getAll()` always return a new array reference, which will immediately break any `useMemo` dependency array tracking them unless they are stringified or deeply compared first.
**Action:** Always refactor synchronous `useCallback` invocations to a single `useMemo` block. When tracking array returns from React Router's `useSearchParams`, memoize the output array by checking against a `JSON.stringify` of the raw array, rather than depending on the raw array directly.
