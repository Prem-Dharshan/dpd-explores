## 2025-05-18 - Prevent Unnecessary Re-renders from React Router `searchParams.getAll()`
**Learning:** `useSearchParams()[0].getAll()` returns a new array reference on every render, which causes `useMemo` or `useCallback` to recompute on every render if passed directly into the dependency array. Furthermore, invoking a `useCallback` directly during the render phase (e.g. `const displayedPlaces = filtered()`) effectively acts like unmemoized synchronous code since the filtering runs immediately anyway.
**Action:** For synchronously derived state, use `useMemo` directly instead of invoking `useCallback`. To memoize dependencies from `searchParams.getAll()`, assign their stringified representation (e.g. `const strVibe = JSON.stringify(vibeFilter)`) to a separate variable, pass that stringified variable to the dependency array, and use `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the missing raw array dependency warning.
