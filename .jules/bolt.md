## 2024-08-18 - [Fix React Router useSearchParams Re-renders]
**Learning:** `searchParams.getAll()` from React Router returns a new array reference on every render. If this array is directly used as a dependency in hooks like `useCallback` or `useMemo`, it breaks memoization and causes continuous re-evaluations and re-renders, impacting performance. `JSON.stringify()` directly in the dependency array triggers linting errors.
**Action:** Stringify the array into a separate variable before the hook (`const stringifiedArray = JSON.stringify(rawArray)`), pass this stringified variable to the dependency array, and use `// eslint-disable-next-line react-hooks/exhaustive-deps` to satisfy ESLint. Also, for synchronously derived state that is recalculated purely based on variables, `useMemo` should be directly used instead of defining a `useCallback` and invoking it immediately on every render.
