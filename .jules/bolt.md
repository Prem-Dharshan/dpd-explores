## 2024-05-18 - [Fix React Re-renders from useSearchParams and useCallback]
**Learning:** `useSearchParams()[0].getAll()` returns a new array reference on every render, causing infinite loops or unnecessary re-renders if used directly in dependency arrays without stringification memoization. Additionally, using `useCallback` to compute derived state and immediately calling it inside the component body is an anti-pattern that defeats memoization since the array operations run on *every* render anyway.
**Action:** When working with search params arrays, memoize the raw array by passing its JSON.stringify string to a `useMemo` dependency array (using `// eslint-disable-next-line react-hooks/exhaustive-deps`). For derived state (like filtering/sorting a list), always use `useMemo` directly so the computation only runs when its dependencies actually change.
