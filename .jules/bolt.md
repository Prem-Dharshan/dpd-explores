## 2024-08-06 - [React Router searchParams.getAll() triggers unmemoized re-renders]
**Learning:** React Router's `useSearchParams()[0].getAll()` returns a new array reference on every render. Using it as a dependency in `useCallback` or `useMemo` causes continuous re-evaluations, defeating the purpose of memoization for expensive synchronous derived state computations (like O(N log N) filtering/sorting).
**Action:** When extracting arrays from URL search params, stringify them and memoize the raw array against the stringified value, disabling `exhaustive-deps` for the raw array if necessary, to ensure stable references across renders. Additionally, always compute synchronous derived state using `useMemo` rather than wrapping it in a `useCallback` and invoking it immediately.
