## 2024-07-25 - React useCallback vs useMemo on List Render
**Learning:** In React components like the Dashboard, wrapping a filtering/sorting operation in `useCallback` does not prevent the operation from running on every render if the function is immediately invoked (e.g., `const displayedPlaces = filtered()`). This effectively causes an O(N log N) re-computation on every single state change, creating severe UI jank as the list grows. Furthermore, reading values like `searchParams.getAll()` directly inside `useMemo` breaks React Compiler's automatic memoization unless `searchParams` itself is passed as a dependency, because manual caching isn't preserved if external mutable references are consumed inside the block without explicit dependency listing.
**Action:** Use `useMemo` for derived state computations, not `useCallback` that gets immediately invoked. When reading array values from URL search parameters within a memoized block, include the underlying `searchParams` object in the dependency array or compute them outside the hook to preserve referential stability and allow React Compiler to successfully optimize the code.
