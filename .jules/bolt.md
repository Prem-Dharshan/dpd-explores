## 2024-05-19 - Dashboard.tsx Memoization Fix
**Learning:** In React Router, `useSearchParams()[0].getAll()` returns a new array reference on every render. This breaks memoization dependencies when directly passing these arrays (like `vibeFilter` or `occasionFilter`) to `useMemo` or `useCallback`. Furthermore, assigning derived state like filtering logic directly inside a `useCallback` and executing it on render is an anti-pattern that defeats memoization entirely.
**Action:** Stringify arrays derived from `searchParams.getAll()` (e.g. `const vibeFilterStr = JSON.stringify(vibeFilter)`) and pass the stringified version in the dependency array with an `eslint-disable-next-line react-hooks/exhaustive-deps` comment. Also use `useMemo` properly for derived state rather than creating and invoking a `useCallback` on render.
