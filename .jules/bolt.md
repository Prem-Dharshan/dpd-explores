## 2025-05-16 - React Router searchParams.getAll() breaks memoization
**Learning:** In React Router, `useSearchParams()[0].getAll()` returns a new array reference on every single render. Using it directly in dependencies of hooks like `useCallback` or `useMemo` will silently break memoization and cause continuous cascading recalculations.
**Action:** Extract the raw array, assign `JSON.stringify(rawArray)` to a variable, and pass that variable to the dependency array. Memoize the raw array explicitly with `useMemo`, and use `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the missing raw array dependency warning. Ensure any synchronously derived state like `filtered` is directly computed via `useMemo` rather than wrapped in a `useCallback` that is immediately invoked.
