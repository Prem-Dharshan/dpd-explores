## 2026-09-01 - Avoid derived state recalculation loops via useCallback and searchParams.getAll()

**Learning:** `useSearchParams()[0].getAll()` returns a new array reference on every render. When using derived state in React components, defining the computation logic using `useCallback` and subsequently invoking it unconditionally inside the component body breaks memoization and forces recalculation on every render. Furthermore, using unstable array references returned from `getAll()` directly in dependency arrays triggers exhaustive-deps warnings, but using `JSON.stringify()` inline causes missing dependency warnings.
**Action:** Use `useMemo` to directly memoize derived arrays instead of defining functions with `useCallback` that run every render. Stringify the unstable arrays returned by `getAll()` into intermediate variables (e.g., `const str = JSON.stringify(arr)`) and pass the stringified variables in the `useMemo` dependency array to preserve stable references, using `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the rule while keeping the memoized return valid.
