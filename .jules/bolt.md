## 2024-05-14 - Fix unmemoized filtering arrays in Dashboard
**Learning:** `useSearchParams()[0].getAll()` returns a new array reference on every single render in React Router. This breaks memoization if passed directly to dependency arrays for `useMemo` or `useCallback`. Furthermore, applying filtering logic to derived state should utilize `useMemo` natively rather than an immediately-invoked `useCallback`, which executes on every render if memoization is broken.
**Action:** Always assign the result of `searchParams.getAll()` to a stringified variable (`JSON.stringify(rawArray)`) and use that stringified variable in dependency arrays. Suppress the ESLint warning with `// eslint-disable-next-line react-hooks/exhaustive-deps`. For synchronously derived state like filtering, always use `useMemo` directly instead of a `useCallback` that gets invoked every render.
