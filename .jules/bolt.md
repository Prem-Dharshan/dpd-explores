## 2024-03-14 - Replace useCallback with useMemo for Synchronous Render Logic
**Learning:** In the Dashboard component, a `filtered` function was created using `useCallback` and then immediately invoked during render (`const displayedPlaces = filtered()`). `useCallback` returns a function, not a value, so invoking it on every render defeats the purpose and causes the expensive filtering/sorting logic to run every single time the component re-renders (even when dependencies haven't changed, as it's re-executing the newly memoized function).
**Action:** Replace `useCallback` with `useMemo` for synchronously derived state, so the computed array is memoized and only recalculated when its dependencies (`places`, `search`, etc.) actually change. Additionally, ensure array outputs from `searchParams.getAll()` are properly memoized (using stringified JSON in the dependency array) to prevent new object references on every render breaking the `useMemo` dependencies.
