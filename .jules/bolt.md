## 2024-05-15 - React Router searchParams.getAll() breaks referential equality
**Learning:** `useSearchParams()[0].getAll()` returns a new array reference on every render. Passing it directly to a dependency array causes the hook to re-evaluate on every render. Furthermore, wrapping synchronous derived state in a `useCallback` and calling it during render is inefficient, as the callback executes every time anyway.
**Action:** When depending on arrays from `searchParams.getAll()`, assign the stringified value (e.g., `JSON.stringify(arr)`) to a variable, pass the stringified variable into the dependency array, and use `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the ESLint warning. Additionally, use `useMemo` for computing derived state rather than a `useCallback` called on every render.
