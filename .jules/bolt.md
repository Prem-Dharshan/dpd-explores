## 2024-03-20 - [React Router useSearchParams Array Issue]
**Learning:** In React Router, `useSearchParams()[0].getAll()` returns a new array reference on every render. To prevent breaking memoization and avoid 'Expected the dependency list to be an array of simple expressions' errors, avoid `.join(',')` and memoize the raw array explicitly by assigning the stringified array to a separate variable (`const stringified = JSON.stringify(rawArray)`), passing that variable to the dependency array, and using `// eslint-disable-next-line react-hooks/exhaustive-deps`. Additionally, for synchronously derived state, use `useMemo` directly instead of invoking a `useCallback` on every render.
**Action:** Always use `useMemo` for derived arrays and explicitly stringify array outputs from search params before injecting them as dependencies to avoid unnecessary executions of filter/sort logic.
