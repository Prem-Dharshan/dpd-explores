## 2024-02-23 - URLSearchParams getAll() array stability
**Learning:** `URLSearchParams.getAll()` returns a new array reference on every render, which breaks memoization when passed directly as a dependency. Attempting to use `useCallback` directly to compute derived state that is invoked on every render causes unnecessary execution.
**Action:** When extracting array params for filtering, memoize them cleanly by using `useMemo(() => rawArray, [JSON.stringify(rawArray)])` and suppressing the `exhaustive-deps` warning with `// eslint-disable-next-line react-hooks/exhaustive-deps`. Additionally, use `useMemo` directly for synchronously derived state instead of an immediately invoked `useCallback` to prevent unnecessary recalculations on re-renders, and ensure all dependencies are included in the dependency array.
