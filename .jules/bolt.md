## 2024-09-17 - React Router `useSearchParams` and Memoization Anti-pattern
**Learning:** In React components dealing with URL search parameters via `useSearchParams()[0].getAll()`, the method returns a new array reference on every render. Passing this directly to `useMemo` or `useCallback` dependency arrays breaks memoization. Furthermore, defining a `useCallback` hook but immediately invoking it during the render cycle (e.g., `const filtered = useCallback(...); const displayed = filtered();`) defeats the purpose of the hook entirely and ensures the expensive logic runs unconditionally on every render.
**Action:** When extracting arrays from URL search params that must be used as dependencies in hooks, serialize them (e.g., using `JSON.stringify()`) to create stable string references for the dependency arrays, and use `// eslint-disable-next-line react-hooks/exhaustive-deps` to safely bypass ESLint warnings about missing raw array dependencies. Additionally, replace immediately-invoked `useCallback`s with `useMemo` to properly memoize the computed result based strictly on its dependencies.
