## 2024-03-24 - React Router useSearchParams memoization break
**Learning:** In React Router, `useSearchParams()[0].getAll()` returns a new array reference on every single render. Using it directly in the dependency array of a `useCallback` or `useMemo` causes the hook to re-evaluate constantly, completely breaking memoization and causing unnecessary re-renders.
**Action:** Stringify the array results from `searchParams.getAll()` into separate variables (`const vibeFilterStr = JSON.stringify(vibeFilter)`) and use those stringified variables in the dependency array instead. Use `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the ESLint warning for the missing raw array dependency. Additionally, for synchronously derived state like filtering a list, use `useMemo` directly rather than defining a `useCallback` and invoking it immediately.
