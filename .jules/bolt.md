## 2026-08-01 - Prevent React-Router useSearchParams from breaking memoization
**Learning:** `useSearchParams()[0].getAll()` from React Router returns a new array reference on every render. If these raw arrays are used as dependencies in `useMemo` or `useCallback` directly, they will break memoization causing expensive functions to re-execute repeatedly. Since arrays returned might contain commas, `.join(',')` shouldn't be used to create a string dependency.
**Action:** Extract raw array values from `searchParams.getAll()` and memoize them explicitly with `useMemo(() => rawArray, [JSON.stringify(rawArray)])` before passing them as dependencies to other hooks. This ensures referential equality is preserved across renders and expensive derived state recalculations are minimized.
