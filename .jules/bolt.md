## 2024-05-24 - [React Router hooks array reference rendering issue]
**Learning:** `useSearchParams()[0].getAll()` from React Router returns a new array reference on every render, which can break memoization (like `useMemo` or `useCallback` dependency arrays) when placed directly inside. This can cause severe performance issues when filtering or sorting logic unnecessarily runs on every single render. Also, calling `useCallback` on every render only to immediately invoke it is an anti-pattern.
**Action:** When using dynamically fetched arrays from `searchParams.getAll()` as dependencies in React hooks, explicitly stringify them (e.g. `JSON.stringify(rawArray)`) and pass the stringified value into the dependency array. Pair it with `// eslint-disable-next-line react-hooks/exhaustive-deps` to satisfy ESLint. Use `useMemo` for synchronously derived state instead of `useCallback`.
