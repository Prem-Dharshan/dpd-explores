## 2025-05-15 - React Router `useSearchParams` Array Reference Re-renders
**Learning:** `useSearchParams()[0].getAll()` returns a new array reference on every single render. Using it directly as a dependency in hooks like `useMemo` or `useCallback` (e.g., `[...places, searchParams.getAll("vibe")]`) will break memoization and trigger unnecessary heavy recalculations (like full-array filtering) on every render cycle, even when the search parameters haven't changed.
**Action:** To prevent breaking memoization, stringify the array using `JSON.stringify()` (assigning it to a separate variable to satisfy ESLint) and pass the stringified variable to the dependency array. Use `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the missing raw array dependency warning. Additionally, for synchronously derived state, use `useMemo` directly instead of invoking a `useCallback` on every render.
