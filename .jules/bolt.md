## 2024-11-20 - React Router searchParams.getAll() breaks memoization
**Learning:** `searchParams.getAll()` from React Router returns a new array reference on every render, which breaks React `useMemo` or `useCallback` when passed directly into the dependency array. The filtering logic in `Dashboard.tsx` was running on every render because `vibeFilter` and `occasionFilter` were new references.
**Action:** When using `searchParams.getAll()`, stringify the returned array into a separate variable (e.g., `const str = JSON.stringify(arr)`) before using it in dependency arrays to preserve memoization and avoid unnecessary re-renders. Use `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the ESLint warning since we are explicitly substituting the raw array dependency with its stringified representation. Also, synchronously derived state like filtering should directly use `useMemo` rather than `useCallback` which requires an explicit execution.
