## 2024-03-22 - Prevent React Router `searchParams.getAll()` from breaking memoization
**Learning:** In React Router, `useSearchParams()[0].getAll()` returns a new array reference on every single render, even when the URL hasn't changed. Using the raw array in a dependency list for `useMemo` or `useCallback` will cause the hook to needlessly re-execute on every render, destroying the cache.
**Action:** When extracting arrays from `searchParams.getAll()`, assign `JSON.stringify(array)` to a separate variable, pass that stringified variable to the dependency array, and use `// eslint-disable-next-line react-hooks/exhaustive-deps` to bypass the missing raw array dependency warning. And for synchronously derived state, use `useMemo` directly rather than invoking a `useCallback` on every render.
