## 2024-09-18 - [Derived State Re-computation Anti-Pattern]
**Learning:** Using `useCallback` to define a function that is immediately invoked on every render to calculate derived state is a significant performance anti-pattern. While it "looks" memoized because of `useCallback`, the invocation `const derivedData = myCallback()` still happens on every single render cycle, wasting CPU cycles on filtering and sorting arrays when dependencies haven't changed. Furthermore, depending directly on values derived from URL `searchParams.getAll()` causes infinite loop risks or busted memoization, as those return new array references on every render.
**Action:** For synchronously derived state, use `useMemo` directly to cache the result. When dealing with dependencies that return new array references on every render (like `searchParams.getAll()`), stringify them first (`const arrString = JSON.stringify(arr)`) and pass the stringified value into the dependency array (using `// eslint-disable-next-line react-hooks/exhaustive-deps` if needed to bypass strict linting rules on raw arrays).
