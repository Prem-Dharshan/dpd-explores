## 2024-09-15 - [Prompt Injection via Mixed Roles & Info Disclosure via Error Leakage]
**Vulnerability:** Found LLM prompt injection vulnerability in Groq API calls where user-provided input (`notes`, `comment`, `moodPrompt`) was concatenated with system instructions inside a single `user` message role. Also found information disclosure vulnerability where `catch (e)` blocks in Vercel API functions were returning raw `String(e)` to clients instead of a generic error message.
**Learning:** LLMs can be manipulated to ignore instructions if untrusted user data is mixed with system prompts, especially in a `user` role context. Additionally, returning raw error objects or strings from serverless functions can leak internal stack traces or API details (like Groq API failures) to potential attackers.
**Prevention:** Strictly separate system instructions using the `system` role and isolate untrusted user data using the `user` role when constructing messages for chat completions API. Ensure all top-level catch blocks in API handlers return safe, generic error messages (e.g., "An error occurred") to clients while logging detailed errors internally.
