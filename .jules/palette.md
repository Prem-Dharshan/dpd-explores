## 2024-05-18 - Missing keyboard interactions on non-semantic buttons
**Learning:** Found an `<img>` used as a user avatar sign-out button that was lacking keyboard interactions (`tabIndex`, keyboard event listener) and semantic roles. Such non-semantic elements must be explicitly given a `role="button"` and `tabIndex={0}`, along with an `onKeyDown` handler to listen for 'Enter' or 'Space' and visible focus states, if they are to be used interactively. Otherwise they are inaccessible to keyboard users and screen readers.
**Action:** Next time, when encountering non-semantic HTML elements acting as interactive controls (like `<img>` or `<div>`), ensure that complete a11y affordances are manually added (`role="button"`, `tabIndex={0}`, `onKeyDown` with Enter/Space handling, and `focus-visible` utility classes).
