## 2026-10-13 - [Focus Rings and Interactive Elements]
**Learning:** For interactive UI controls positioned over dynamic image backgrounds (like image carousel controls), standard theme focus rings (e.g., `ring-accent`) often lack sufficient contrast depending on the image underneath. Using `focus-visible:ring-surface` (the highest contrast solid color) ensures visibility. Additionally, when using non-semantic elements like `<img>` for avatars as clickable actions, explicit keyboard affordances (`role="button"`, `tabIndex={0}`, `onKeyDown` handlers for Enter/Space) and custom focus outlines are required for screen reader and keyboard accessibility, which are easily overlooked.
**Action:** Always check the background context of icon buttons to ensure focus rings are visible. Standardize on `focus-visible:ring-surface` for elements over photos. For any clickable non-semantic element, enforce a checklist: `role`, `tabIndex`, `onKeyDown`, `aria-label`, and `focus-visible` styling.
