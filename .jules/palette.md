## 2024-05-24 - Accessible Icon Buttons & Focus States in Image Carousels
**Learning:** Found an accessibility issue pattern across image carousels and modal dialogs where icon-only controls (carousel arrows, indicator dots, close buttons) lacked both semantic labels (`aria-label`) and visible keyboard focus states (`focus-visible`). This makes keyboard navigation difficult as users can't see which control is focused or understand its purpose. Carousel indicator dots also lacked `aria-current` to communicate the active state to screen readers.
**Action:** When implementing or reviewing custom UI components with icon-only controls, always ensure they have explicit `aria-label` attributes and prominent visual focus indicators using utility classes like `focus-visible:ring-2 focus-visible:ring-accent focus-visible:outline-none`. Use `aria-current="true"` on the active element in a set of indicators.
