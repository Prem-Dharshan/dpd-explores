## 2025-03-01 - Add keyboard accessibility to avatars and icon-only controls
**Learning:** Icon-only controls (like carousel arrows, dot indicators, and modal close buttons) often lack text equivalents, rendering them invisible to screen readers without `aria-label`s. Furthermore, when non-semantic elements like `<img>` tags are used as buttons (e.g., for user avatars), they completely lack native keyboard affordances, meaning they cannot be focused via Tab or triggered via Enter/Space.
**Action:** Next time, actively ensure all icon-only buttons receive a descriptive `aria-label` and `focus-visible` utility classes for keyboard focus. When turning non-semantic elements into interactive ones, explicitly add `role="button"`, `tabIndex={0}`, keyboard event handlers (`onKeyDown`), and visual focus indicators.
