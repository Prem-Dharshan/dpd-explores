## 2024-08-11 - Add accessibility to Avatar & Icon Buttons
**Learning:** For interactive UI elements lacking semantic tag characteristics (like `<img>` tags acting as buttons or icon-only buttons), screen readers and keyboard users require explicit affordances: `role="button"`, `tabIndex={0}`, keyboard event handlers (`Enter`/`Space`), and `aria-label`s. Focus visibility must also be explicitly defined (e.g. using `focus-visible` utility classes) so keyboard users can track their position.
**Action:** Always ensure any interactive elements that are not `<button>` or `<a>` are fully augmented with the necessary ARIA, tabindex, and keyboard event handlers. Additionally, proactively scan for icon-only buttons (like modals X or edit buttons) and add descriptive `aria-label`s and `focus-visible` states.
