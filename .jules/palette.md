## 2024-10-27 - Add missing aria-labels and focus states to custom buttons
**Learning:** React web apps frequently substitute `<button>` elements with `<img>`, `<div>`, or inline SVG elements. When this happens, keyboard accessibility is lost. Custom icon-only buttons need `aria-label`s for screen readers and `focus-visible` styles for keyboard navigation. An `<img>` acting as a button requires `role="button"`, `tabIndex={0}`, and an `onKeyDown` listener to replicate standard `<button>` behavior.
**Action:** Always verify that interactive elements use native semantic tags (like `<button>`). If a non-semantic element must be used (e.g., an avatar `<img>` acting as a menu toggle or logout), explicitly grant it full accessibility affordances (`role`, `tabIndex`, keyboard handlers). Make sure to add `focus-visible:ring-2` to custom icons for visibility during keyboard tabbing.
