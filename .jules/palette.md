## 2026-08-08 - Focus indicators and ARIA labels on photo carousel and modal
**Learning:** Found multiple unlabelled `<button>` tags used as interactive overlays on images or as close buttons for modals in `PlaceDetail.tsx`. These buttons lacked `aria-label`s, which makes them inaccessible for screen readers. Furthermore, because these are icon-only custom buttons (especially the photo indicator dots), they had no explicit keyboard focus visual indicator (`focus-visible`).
**Action:** Always add explicit `aria-label` to icon-only buttons (like `ChevronLeft`, `ChevronRight`, `X`, and dot indicators). Apply custom `focus-visible:ring-2 focus-visible:ring-accent` utility classes to them to ensure keyboard navigability is visually apparent. For dot indicators tracking a state, add `aria-current={i === photoIdx}`.
