## 2023-10-30 - Keyboard Accessibility and Missing ARIA Labels on Buttons
**Learning:** Found that non-semantic `<img>` tags were being used as clickable elements without keyboard accessibility affordances (missing `role="button"`, `tabIndex`, and keyboard event handlers). Additionally, there was a systemic lack of `aria-label` attributes on icon-only buttons across multiple components (e.g., clear inputs, dismiss modals, remove tags).
**Action:** When using non-semantic elements as buttons, explicitly add `role="button"`, `tabIndex={0}`, an `onKeyDown` handler (Space and Enter), and `focus-visible` utility classes for keyboard accessibility. Always ensure icon-only buttons (`<button><Icon/></button>`) have descriptive `aria-label` attributes to ensure they are accessible to screen reader users.
